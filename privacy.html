Privacy Policy

Last updated: October 10, 2026

This policy covers the "rclone Personal Drive Access" OAuth client. Its owner, Sergey Forin, uses it only with his own Google account.

Data accessed

The app uses the Google Drive API to access files in the owner's own Google Drive. Access happens only on the owner's computer through the open-source tool rclone.

Data storage and sharing

  • No data is collected, stored on, or sent to any server other than Google's.
  • OAuth tokens are stored only locally in the rclone configuration file on the owner's device.
  • No data is sold, shared with third parties, or used for advertising or analytics.

Google API Services User Data Policy

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
